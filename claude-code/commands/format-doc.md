# /format-doc

Formata o arquivo Markdown informado de acordo com as normas UNISA / ABNT (margens 3cm/2cm, Arial 12, recuo 1,25cm, 1,5 entrelinhas, cabeçalho oficial e referências NBR 6023).

```bash
format-doc "$1"
```
